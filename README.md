# Blog API

This is a rest API for managing a personal blogging app. It allows for management of blog posts, feedback through comments, comment moderation and so much more.

## Features

- User Creation and Authentication
- Post Management
  - Create, read, update and delete posts.
  - Publishing and unpublishing posts.
- Comment Management
  - Create, read, update and delete post comments.
  - Comment moderation by admins.
